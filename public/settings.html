Password Recovery & Data Backup — what these are

1) Recovery Code

This is a small 8-letter code just for YOU. If you ever forget your login password, click Forgot Password on the login screen and type this code — it will show your password. Please write it in a diary.

--------

2) Your Recovery Email

If your Recovery Code stops working, the developer will reset your password and send the new one to this email.

3) Daily Data Backup

Everything you enter — patients, bills, medicines, purchases, expenses, staff — is saved in ONE file called clinic.db. Click below to download that one file to your computer. Copy it to a pen drive every evening. If your computer breaks, put that same file back into the software folder and everything comes back.
