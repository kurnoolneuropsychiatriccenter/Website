Password Recovery & Data Backup — what these are

1) Recovery Code

This is a small 8-letter code just for YOU. If you ever forget your login password, click Forgot Password on the login screen and type this code — it will show your password. Please write it in a diary.

--------

2) Your Recovery Email

If your Recovery Code stops working, the developer will reset your password and send the new one to this email.

3) Daily Data Backup

Everything you enter — patients, bills, medicines, purchases, expenses, staff — is saved in ONE file called clinic.db. Click below to download that one file to your computer. Copy it to a pen drive every evening. If your computer breaks, put that same file back into the software folder and everything comes back.

The PDF contains every record (patients, bills, medicines, staff, pending medicines, everything) in one printable file — useful for archiving or sharing with your accountant.

Email Setup — one-time setup for security codes

This lets the software send a security code to your recovery email (--) whenever someone tries to delete records from the Danger Zone. Without this, the delete buttons will refuse to work.

How to fill this in (one time only):

  1. Open Gmail on any browser → click your profile picture → Manage your Google Account.
  2. Go to Security → make sure 2-Step Verification is ON.
  3. Below that click App passwords → give it a name like "Clinic PC" → Google will show a 16-letter password.
  4. Copy the 16-letter password and paste it below along with your Gmail address. Click Save.
  5. Then click Send Test Email below to make sure it works.
